# 내 자막 규칙 (자유롭게 고쳐도 돼요 — 자막 만들 때마다 AI가 이 파일을 읽어요)

## 줄 끊기
1. 문장이 끝나면(…요 / …다 / …지? / …어 / …네 등) 무조건 줄을 끊는다.
   다음 문장의 첫 단어를 앞 줄 끝에 붙이지 않는다.
   ✗ "보니까 부드러워요 제가" → ✓ "보니까" / "부드러워요" / "제가 한번 보여드릴게요 진짜"
2. 말하는 사람이 바뀌면 줄을 끊는다. 주고받는 말은 각각 한 줄.
   ✗ "5개 주세요 5개 갈게요" → ✓ "5개 드세요" / "5개 갈게요"
3. 한 단어(어절)를 두 줄에 나누지 않는다.
   ✗ "받았어 먹어 다 먹어 한" / "번에 먹어" → ✓ "한번에 먹어"
4. 짧아도 괜찮다. "진짜", "아", "맛있지?" 처럼 한두 단어짜리 줄도 OK.
   줄을 꽉 채우는 것보다 '어디서 끊느냐'가 더 중요하다.
5. 긴 문장은 말의 호흡(의미 덩어리)대로 나눈다.
   "이거 바로 한번 가보도록" / "하겠습니다", "자 각자 수능 횟수만큼" / "먹어서 진정성을"
6. 말이 잠깐 멈춘 곳(간격이 있는 곳)은 줄을 끊는 좋은 위치다.

## 표현
7. 예능 말맛을 살린다: 늘이는 말 "~"(이번엔 김유연~), 말끝 흐림 ",,,,"(와,,,, / 혹시 한 번 더,,,,),
   웃음 "ㅋㅋ"(누가 초콜릿을ㅋㅋ).
8. 말이 아닌 동작·장난 멘트는 괄호로: "(이렇게 먹어줘요)".
9. 잘못 들린 단어는 문맥에 맞게 고친다. 확실하지 않은 의미 없는 소리는 빼도 된다.

## 초록 상황 자막
10. 장면(상황)이 바뀌는 지점에 단다. 대사 내용을 반복하지 않는다.
11. 같은 상황이 이어지면 연속된 줄에 같은 문구를 그대로 반복해도 된다.
12. 첫 줄은 지금 무슨 장면인지 알려주는 짧은 말 (예: "음미 시작").
